# Regional information support

This repository contains aggregate data for *Regional variation in information maintenance and team signalling in online cooperation*.
The study examines information practices among 126,000 League of Legends players on North American, Western European and Korean servers.

## Data

The dataset covers four main figures, seven supplementary figures, the main table and all 74 supplementary subtables.
It includes unrounded estimates, variable definitions and the captions and notes needed to interpret the results.

- [Data guide and import examples](data/README.md)
- [Figure index](data/metadata/figure_index.csv)
- [Table index](data/metadata/table_index.csv)
- [Variable dictionary](data/dictionaries/variables.csv)

The data correspond to the manuscript version of 23 September 2026.
The [data guide](data/README.md) explains measurement units, sample sizes and the scope of the aggregate files.
